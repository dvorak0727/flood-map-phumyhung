風險怎麼算 / 注意事項

每個點位取所屬分區的 24 小時逐時預報：
分數 = max(未來1h雨量×2, 未來3h累積, 未來24h累積×0.4) × 地勢係數（高 1.6／中 1.2／低 0.8）。
<8 正常；8–20 注意；20–40 警戒；≥40 危險。
若填了潮位且 ≥ 門檻，地勢係數 ≥ 中的點位再升一級（潮汐是 Nhà Bè／Phú Thuận 淹水主因之一，Weather API 不含潮位，需手動輸入）。

預設點位座標與地勢係數是依常見積水路段估計的約略值，不是官方資料，請用「新增點位」或自行修改程式內 BASE_POINTS 校正。此頁僅供參考，不能取代胡志明市官方防洪通報。

需在 Google Cloud 啟用：Maps JavaScript API、Weather API。若 KEY 設了 HTTP referrer 限制，請用 http://localhost 開啟，直接雙擊 file:// 可能被擋。
